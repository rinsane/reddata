Already have Reddit API credentials?

Reddit closed self-service API keys in November 2025, so new apps need approval first. If you hold credentials from before then, connect them for a live view that skips the bookmarklet.

Connect an app
  1. Open reddit.com/prefs/apps
  2. Create app → type web app
  3. Set the redirect uri to exactly
  4. Client id sits under the app name; the secret is labelled secret
