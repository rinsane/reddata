Connect your Reddit app

Reddit has no single API key. Create a web app on Reddit, then paste the client id and secret here. Credentials stay in this browser.

  1. Open reddit.com/prefs/apps
  2. Create app → type web app
  3. Set redirect uri to exactly:
  4. Copy the client id (under the app name) and the secret

Relationship

    Calls go through a tiny Cloudflare Pages Function so the browser never talks to Reddit directly. Nothing is stored on a server.
