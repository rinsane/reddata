Grab without an API key

Reddit closed self-service API keys in November 2025. Until yours is approved, you can still read your own subscriptions from a tab you are already signed in to.

  1. Drag this button to your bookmarks bar →  Grab my subs
  2. Open reddit.com and make sure you are signed in
  3. Click the bookmark. It saves reddit-subs.json
  4. Drop that file below

The bookmark only runs on reddit.com, because only a reddit.com tab may read your Reddit session. This page cannot do it for you — your browser blocks that, which is exactly what stops any other site from reading your account. Nothing is uploaded anywhere.
